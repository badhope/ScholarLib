# Rubbish 编辑规范（Editorial Standards）

> 版本 1.1 · 2026-10-27 · 适用于两个赛道（正经 / 荒诞），对所有稿件同等生效。
> 本文件是投稿模板与作者指南的上位文件；冲突时以本文件为准。
> 修订需编辑会议通过，并在 CHANGELOG 记录。

## 一、定位与自我约束

Rubbish 是一家**正经与荒诞兼容**的开放获取期刊。我们不把自己包装成 JCR 收录期刊，
也不假装与国际评价体系对齐；我们碰瓷学术的形式，但把形式做真：**格式认真、引用真实、
论证完整、结论可被反驳**。

三条自我约束：

1. **不编造数据**。所有数字必须有来源；模拟研究必须显式标注「本文数值来自模拟」，
   并给出参数表与可复现脚本。
2. **不编造引用**。每一条参考文献都必须能在 DOI 或公开数据库核实；
   编造引用一经发现即退稿，并记入作者信用记录。
3. **不伤人**。荒诞可以指向体制、惯例、学科本身，不可以指向真实个人的隐私与名誉。

## 二、篇幅分档

| 档位 | 正文字数（汉字） | 典型结构 | 图表下限 | 文献下限 |
|---|---|---|---|---|
| 短篇 Short | 2,500–5,000 | 3–5 个一级节 | 2 | 4 |
| 中篇 Medium | 5,000–8,000 | 5–8 个一级节，含相关工作 | 3 | 8 |
| 长篇 Long | 8,000 以上（不设上限） | 7 个以上一级节，含完整相关工作与讨论 | 4 | 10 |

篇幅是**下限而非上限**：内容撑不住的长篇会被要求删减，撑得住的短篇不会因短而减分。
目录标注篇幅档位，读者可据此选择。

## 三、结构规范（强制）

### 3.1 必须有的节

| 节 | 功能 | 缺失后果 |
|---|---|---|
| 引言 | 现象 → 研究缺口 → 本文贡献 | 退修 |
| 相关工作 | 有立场的分组梳理（不是文献堆砌） | 退修 |
| 方法 / 论证框架 | 正经：数据、样本、变量、模型；荒诞：材料、编码、论证逻辑 | 退修 |
| 结果 | 按「总—分」呈现，每节对应图表 | 退修 |
| 讨论 | 含义 → 局限 → 启示（实践/政策） | 退修 |
| 结论 | 重申发现、含义、后续方向 | 退修 |

### 3.2 摘要四要素

200–350 字，必须包含：**问题**（研究什么）、**方法**（怎么做的）、**结果**（发现了什么）、
**结论**（意味着什么）。禁止「本文具有重要意义」「填补了空白」这类没有信息量的句子。

### 3.3 可选但推荐

- JEL 分类（经济学）、MSC 分类（数学/计算机）
- 数据与代码可用性声明（**实际为强制**，见 5.1）
- 作者贡献（CRediT 分类，**实际为强制**，见 5.2）

## 四、图表规范

### 4.1 图

- 编号连续（图 1、图 2……），标题在**图下方**；
- 坐标轴必须有量与单位；图例必须可读（不依赖颜色区分单一维度）；
- 分辨率 ≥ 300 dpi，位图格式 ≥ 1000 px 宽；
- 图注最后一行写**数据来源**；模拟数据必须写明「模拟」；
- 正文必须显式引用（如「见图 2」），不允许「图见下」这类占位。

### 4.2 表

- 编号连续（表 1、表 2……），标题在**表上方**；
- 采用**三线表**（顶线、表头线、底线），不使用竖线；
- 单位写在表头内（如「耗时（ms）」），不在单元格内重复；
- 显著性标记须在图注/表注中说明（p<0.05、p<0.01 等）。

### 4.3 视觉一致性

同一篇稿件内的图表使用同一套配色与字号；颜色不作为唯一编码维度
（需同时用线型、标记或直接标注），以满足色觉障碍读者。

## 五、声明（强制）

### 5.1 数据与代码可用性

三选一，不能空着：

1. **已公开**：给出仓库地址或 DOI；
2. **可索取**：说明向谁、以何种方式索取，以及合理的响应时限；
3. **受限**：说明限制原因（伦理、商业、隐私）与申请流程。

### 5.2 作者贡献

按 CRediT 十四类写：概念化、方法学、软件、验证、形式分析、调查、资源、数据管理、
写作—初稿、写作—审阅编辑、可视化、监督、项目管理、经费获取。

### 5.3 利益冲突

有就写；没有写「作者声明无利益冲突」。作者与本刊编辑部存在隶属关系时必须声明，
该稿由**外部编辑**独立处理。

## 六、引用规范

- 采用 **GB/T 7714-2015 顺序编码制**：正文按出现顺序标 [1][2]，文末同序排列；
- 每条文献必须包含 **DOI**（有 DOI 的文献），没有 DOI 的书籍须给出 ISBN 或出版社；
- 文献类型标识：期刊 [J]、专著 [M]、析出 [M]//、会议 [C]、学位论文 [D]、标准 [S]、报告 [R]；
- **禁止**引用不可核实的来源（自媒体截图、聊天记录、无出处的「业内人士称」）；
- 自引不超过总量的 20%；引用本刊文章不受限制，但须与论证相关。

**真实性核验**：编辑部在初审阶段对每条文献做 DOI 抽查（≥ 30% 抽样）。抽查不通过即退稿。

## 七、格式与提交

### 7.1 文件格式

| 格式 | 适用 | 说明 |
|---|---|---|
| Markdown | 推荐 | 站内在线阅读效果最佳；图表用 PNG 引用或 base64 内嵌 |
| PDF | 通用 | 需同时提交源文件（.md/.docx/.tex）以便排版 |
| Word (.docx) | 通用 | 图表须为可编辑对象，不要整页截图 |
| LaTeX | 公式多 | 用 xelatex 编译，附 .tex 与图片 |

不接受：纯图片 PDF（扫描件）、无源文件的排版稿、压缩包内混放多个版本。

### 7.2 排版细则（若自排）

- 纸张 A4，页边距上下 2.8 cm、左右 3.0 cm；
- 正文中文宋体 10.5–12 pt，行距 1.5–1.7 倍；
- 一级标题黑体 12–14 pt，二级标题黑体 11–12 pt；
- 首行缩进 2 字符；段间不空行（或统一空 0.5 行，全文一致）；
- 页码连续，页眉含刊名与篇名（可选）。

### 7.3 提交清单

投稿前请确认：

- [ ] 摘要 200–350 字、四要素齐全
- [ ] 六个必需节齐全
- [ ] 图表编号连续、正文引用、图注含数据来源
- [ ] 参考文献 ≥ 8 条、GB/T 7714-2015、可核实
- [ ] 三段声明（数据可用性 / 作者贡献 / 利益冲突）齐全
- [ ] 全体作者已知情同意署名与排序
- [ ] 文件格式符合 7.1，附源文件

## 八、评审与决定

- **双盲评审**为默认模式；作者可在投稿时申请单盲（需说明理由）；
- 每篇稿件至少两位审稿人；分歧较大时由编辑追加第三位；
- 四类决定：接收、小修、大修、拒稿。小修/大修须在 30 日内返回修改稿，
  逾期视为撤稿（可申请一次延期）；
- **申诉**：作者可在决定后 30 日内提出一次申诉，由未参与原审的编辑处理。

## 九、荒诞赛道的特别说明

荒诞赛道的稿件在**格式与引用上适用完全相同的标准**，差别只在选题与语气：

- 选题可以离谱（奶蛙、摸鱼、茶歇），但必须说明「为什么它值得严肃研究」；
- 语气可以幽默，但不许口水化；幽默应来自论证本身的反差，而非网络段子；
- 引用必须真实，且与论证相关——用一篇严肃的弱关系文献支撑茶歇研究，是荒诞赛道最标准的做法；
- 结论必须诚实：如果研究本身就是荒诞的，请在讨论里说出来。

**一句话**：荒诞是选题的自由，不是格式的豁免。

## 十一、AI 辅助写作

### 11.1 立场

本刊**不禁止** AI 辅助写作，但要求作者对内容负全责。禁止的是「用 AI 掩盖内容空洞」——
生成后未核实、未改写、未加入任何真实经验的稿件。

### 11.2 三项硬指标（初审即查）

1. **因果是否成立**：每个「因此 / 由此可见」前后必须能对上因果，并已考虑竞争解释。
2. **引用是否可核实**：每条参考文献必须能打开 DOI。抽查 30%，任一条不可核实即退稿。
3. **结论是否超出证据**：结论的适用范围不得大于样本能支持的范围。

三项不过，文风再好也退；三项都过，用不用 AI 不是问题。

### 11.3 不应作为判据的东西

- **AI 检测工具的分数**：已有研究显示这类检测器对非英语母语作者存在系统性误判。
- **连接词密度、术语密度**：可作为提示，不可作为证据。
- **段落长度**：同上。

### 11.4 声明

AI 辅助必须在致谢或专门的「作者贡献」中声明工具与用途（例如「使用 X 润色英文摘要，
论证与数据均由作者完成」）。**未声明不必然退稿，隐瞒一定退稿。**

### 11.5 完整核查表

见 `docs/ai-writing-checklist.md`（线上 `/templates/rubbish-ai-writing-checklist.md`）：
列出因果断裂、循环论证、编造引用、小数位过度精确、三段式空转、段落长度均匀等
十余个具体症状，每个症状给出坏例、好例与核查方法。

## 十二、版本 1.1 追加（2026-10-27 创刊）

本次改版不改变正文写作要求，只把「怎样算合格」落到可复现的口径上：

1. **四类稿件画像**：研究论文 / 综述 / 随笔评论 / 研究简报。结构、篇幅、引用下限按画像分别设定，
   不再用一套论文标准衡量所有体裁。见 `GET /api/quality/rubric`。
2. **RQS v1.0 质量评分**：七维加权（结构、篇幅、引用、图表、摘要、排版、语言），
   满分 100，等级 A+ / A / B / C / D，纯度系数 = RQS / 50。权重冻结在代码中，
   改版需升 `RUBRIC_VERSION` 并整库重评。
3. **等级决定投稿权限**：L1 读者 → L2 社区成员 → L3 作者。投稿前必须在个人中心
   确认本规范（`rules_ack_version` 落库）；规范改版后需重新确认。
4. **引用真实性的机检**：编辑部在入库前对全部 DOI 做 Crossref 解析；
   解析失败率写入该文的评分明细（references 维度的 doi_resolved 项）。
5. **声明仍然是强制的**：数据可用性 / 作者贡献 / 利益冲突三段，缺一即退修。
   荒诞赛道不豁免。
