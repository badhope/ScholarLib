一、快速开始

注册账号

  1. 打开首页，点击右上角「注册」。
  2. 填写邮箱、用户名和密码（密码建议 12 位以上，含大小写字母、数字和符号）。
  3. 注册成功后会直接登录；如需邮箱验证，请查收验证邮件。

登录

用 用户名或邮箱 + 密码登录（邮箱不分大小写）。如果账号开启了双因素认证（TOTP），登录后还需输入验证器 App 里的 6 位动态码。

平台的角色：读者、作者、审稿人、编辑、栏目编辑，管理员（is_admin）另算且拥有全部权限。同一账号可以拥有多个角色，实际能看到的菜单由角色决定：审稿人可见「审稿工作台」，编辑与栏目编辑可见「编辑工作台」，管理员额外可见「用户管理 / 角色申请 / 审计日志」等站点管理项。

个人简介

登录后进入「账号设置 → 资料」，可以写一句 ≤200 字的个人简介，展示在你的个人中心等级卡上。

二、作者：投稿与修订

步骤操作
1. 新建投稿登录后进入「我的投稿」→「新建投稿」，填写标题、类型（论文 / 图书 / 数据集 / 教程）、作者、年份、学科、关键词和摘要。
2. 上传文件保存后进入稿件详情，上传 PDF 全文。系统会保存每个版本的快照，历史版本随时可查。
3. 跟踪状态稿件状态：待审 → 外审中 → 大修 / 小修 → 录用 / 拒稿。每次状态变化都会收到站内通知。
4. 修订重投收到修改意见后，在稿件页提交新版本（可附说明），编辑会看到完整版本链。
双盲评审时，审稿人看到的是匿名化的稿件信息，作者身份不会泄露。

三、审稿人：接单与提交意见

  1. 进入「审稿工作台」，可以看到指派给你的审稿任务。
  2. 点「接受」开始审稿（如与作者有利益冲突，可选「拒绝」并说明原因）。
  3. 阅读稿件（支持浏览器内直接看 PDF），填写评分与意见：
    • 给作者的意见：会匿名转达给作者；
    • 给编辑的意见：仅编辑可见；
    • 审稿建议：录用 / 小修 / 大修 / 拒稿。
  4. 提交后任务完成，可在工作台查看历史记录。

四、编辑：指派与裁决

  1. 「编辑工作台」列出所有待处理稿件，可按状态筛选。
  2. 为稿件指派 1–3 名审稿人，可设置截止日期。
  3. 审稿意见回来后，在稿件页做裁决：录用 / 小修 / 大修 / 拒稿，并填写编辑备注。
  4. 录用后稿件会自动进入公开目录，读者可检索与在线阅读。
编辑还可以在「期刊 / 卷 / 期」管理中维护出版物结构，在「批量导入」里用 BibTeX / RIS / CSV / DOI / arXiv 导入已有文献。

五、读者：检索与阅读

  • 目录检索：首页或「资源目录」支持关键词、学科、类型筛选。
  • 在线阅读：详情页内置 pdf.js 阅读器，无需下载即可阅读，支持翻页与缩放。
  • 阅读进度：登录后自动记录每篇文章读到第几页，换设备也能接着读。
  • 关注作者：在作者页点「关注」，该作者有新作时会收到通知。
  • 通知订阅：在「通知」页管理订阅，可选择邮件或站内提醒。
  • 收藏夹：「我的图书馆」可建立多个收藏列表，按主题整理文献。

六、账号安全

  • 修改密码：右上角头像 → 账号设置 → 安全。
  • 开启双因素（推荐）：安全页 → 绑定 TOTP，用 Google Authenticator / 微软 Authenticator / 1Password 扫码，之后登录需输入 6 位动态码。
  • 通行密钥（WebAuthn）：支持指纹 / 面容 / 安全密钥登录，比密码更安全。
  • 登录设备：修改密码后，其他设备上的登录会被强制失效。
请勿把账号借给他人使用。审稿人账号涉及未发表稿件，泄露可能造成学术不端风险。

七、投稿规范

项目要求
稿件格式PDF 全文；正文中/英文均可；建议使用宋体 / Times New Roman，字号不小于 10pt。
篇幅研究论文建议 6–20 页；短文 / 数据集描述 2–6 页。
摘要200–500 字，包含研究问题、方法、结果与结论四要素。
关键词3–6 个，用分号分隔，按重要性排序。
参考文献采用 GB/T 7714 或 APA 格式，文内引用与文末列表一一对应。
署名作者名单投稿后不可随意增删；署名单位写到二级机构；通讯作者需标注邮箱。
伦理声明涉及人体 / 动物实验需提供审批号；引用他人成果必须注明出处，一稿多投将被拒稿并记录。
利益冲突存在利益冲突时需在稿件末页声明；审稿人与作者有合作关系时应主动回避。
示例（摘要开头）：“本文以……为对象，从……四个维度进行比较分析，结果显示……”——四要素缺一不可。

八、审稿人守则

  1. 时限：接受任务后 2–3 周内提交意见；无法按时完成请提前拒单并说明。
  2. 保密：稿件内容、数据与结论在发表前不得向任何第三方透露，不得使用 AI 工具代写评审意见。
  3. 回避：与作者有合作、师生、竞争关系时应拒绝该任务。
  4. 评审要点：原创性、方法严谨性、数据与结论一致性、表达清晰度——按四维评分并给出可操作的具体意见。
  5. 意见写法：给作者的意见要具体到节 / 页（例：“第 3 节缺少 baseline 对比，建议补充表 X”），避免只有“质量不行”这类空泛结论。
  6. 独立性：意见由本人独立形成，不受编辑或其他审稿人影响。

九、编辑与出版规范

  1. 初审：编辑部在 5 个工作日内完成形式审查（格式、范围、伦理），不合格直接退回。
  2. 送审：每篇稿件指派 2–3 名审稿人，审稿模式（单盲 / 双盲）由期刊设置统一决定。
  3. 裁决：收齐意见后 5 个工作日内做出录用 / 小修 / 大修 / 拒稿决定，并附编辑备注。
  4. 修订：大修稿件作者须在 30 天内重投；编辑核对逐条回应后方可录用。
  5. 发布：录用稿件进入公开目录，元数据（年份 / 学科 / 关键词）必须完整，以便检索与引用。
  6. 申诉：作者对裁决有异议可邮件申诉，由主编组织第三方复审，结果为终局。

十、等级与升级

每日签到

「等级与规范」页顶部可以每日签到：每天 +2 XP，连续每满 7 天额外 +5 XP。签到是免费的，断签只影响连签奖励，不清空已有 XP。

等级怎么达到
L1 小白读者注册即是（注册登录后即可投稿）。
L2 注册读者个人中心确认社区规范（+30 XP），解锁评论 / 关注 / 收藏。
L3 作者确认《投稿规范》（+120 XP）——这也是投稿的唯一前置，确认完就能投。
L4 常驻作者投稿并录用后自动获得（积分还需满 400——只攒积分不投稿升不了级）。
L5 审稿人申请制：至少 1 篇稿件被本刊录用，且最高质量分（RQS）≥ 60。到「等级与规范」页提交申请，编辑部批准后解锁审稿工作台。
L6 资深审稿人申请制：已是审稿人（L5）且完成审稿 ≥ 5 份。同一页面申请。
L7–L9 编辑职不开放申请，由编辑部根据审稿质量与贡献直接提拔。
注册账号默认是普通级别（L1 读者），注册登录后即可投稿（首次投稿需确认《投稿规范》）；L4 起看投稿硬指标——录用才是升级的重磅，只攒积分升不了级；职员角色（审稿人 L5/L6）走「申请 → 编辑部审批」，编辑职（L7 以上）只接受管理提拔。资格进度在「等级与规范」页实时可见，差多少一目了然。

十一、常见问题

忘记密码怎么办？

登录页点「忘记密码」，通过邮箱重置。若邮箱不可用，请联系管理员。

投稿后多久有结果？

取决于编辑指派审稿人的速度，通常 2–6 周。状态变化会通过站内通知告知。

能投稿非 PDF 格式吗？

目前稿件全文需为 PDF。图片、数据集可作为补充材料单独上传。

稿件被拒还能再投吗？

可以。按意见修改后作为新投稿提交，并在 cover letter 中说明与前次投稿的关系。

阅读时 PDF 加载不出来？

先刷新页面；若仍失败，请确认文件已成功上传（详情页应显示文件大小），或联系管理员。
