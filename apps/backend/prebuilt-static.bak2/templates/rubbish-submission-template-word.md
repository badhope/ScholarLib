# Rubbish 投稿模板（Word 版排版要求）

> 版本 2.0 · 2026-11 · 对应《Rubbish 编辑规范》§3 结构与 §4 图表
>
> **使用方式**：在 Word 里按下列样式设置好「标题 1 / 标题 2 / 正文 / 图表题注」四个样式，
> 之后全篇套用即可。不要手动逐个调字号——手调出来的稿子转 PDF 后层级会乱，
> 我们的自动识别也读不出来。

## 一、页面与基础样式

| 项目 | 要求 |
|---|---|
| 纸张 | A4（210 × 297 mm） |
| 页边距 | 上下 2.54 cm，左右 3.17 cm（Word 默认「普通」） |
| 正文中文字体 | 宋体（SimSun）/ 思源宋体 |
| 正文西文字体 | Times New Roman |
| 正文字号 | 小四（12 pt） |
| 行距 | 1.5 倍（或固定值 22 pt） |
| 段前段后 | 0 |
| 首行缩进 | 2 字符（不要用空格！用「段落 → 特殊格式 → 首行缩进 2 字符」） |
| 对齐 | 两端对齐 |

> **不要做**：不要用空格做缩进、不要用回车换页、不要手动加编号（如「1.」）——
> 用 Word 的「多级列表」或直接写「1 引言」让样式层级生效。

## 二、标题层级

| 层级 | 样式名 | 字体 | 字号 | 加粗 | 段前/段后 |
|---|---|---|---|---|---|
| 论文标题 | 标题 | 黑体 | 二号（22 pt） | 是 | 0 / 12 pt |
| 一级节 | 标题 1 | 黑体 | 四号（14 pt） | 是 | 18 pt / 8 pt |
| 二级节 | 标题 2 | 黑体 | 小四（12 pt） | 是 | 12 pt / 6 pt |
| 三级节 | 标题 3 | 楷体 | 小四（12 pt） | 是 | 10 pt / 4 pt |

一级节编号写「1 引言」而不是「第一章」——本刊不设「章」。

## 三、摘要与关键词

- 「摘要」二字用**黑体小四**，与正文同段开头，后面直接接内容（不要单独一行占位）。
- 摘要 200–350 字，含**问题 / 方法 / 结果 / 结论**四要素。
- 「关键词：」用**黑体小四**，后接 4–6 个词，用分号「；」分隔。

## 四、图表规范

### 图

- 图**居中**，宽度不超过正文宽度。
- 图题在**图下方**，格式：`图 1　图题`（图号与图题之间用全角空格），
  用**楷体五号**、居中、不加粗。
- 图内不要嵌文字标题——标题由正文图题提供。
- 分辨率 ≥ 300 dpi；位图宽度 ≥ 1000 px。**不要整页截图**。

### 表

- 用**三线表**：顶线（1.5 pt）、表头线（1 pt）、底线（1.5 pt），**不要竖线**
  （Word：选中表格 → 边框和底纹 → 只保留上下框线与表头下框线）。
- 表题在**表上方**，格式：`表 1　表题`，**楷体五号**、居中。
- 单位写在表头内，如「耗时（ms）」，不在单元格里重复。
- 表内文字五号（10.5 pt），数字右对齐或小数点对齐。

## 五、公式

- 用 Word 自带公式编辑器（插入 → 公式），**不要用图片代替公式**。
- 独立公式居中，编号右对齐，格式 `(1)`、`(2)`。
- 行内变量用斜体，单位用正体。

## 六、参考文献

- 格式：**GB/T 7714-2015 顺序编码制**。
- 正文引用写 `[1]`、`[1,2]`、`[1-3]`（上标由排版阶段处理，正文写方括号即可）。
- 文末「参考文献」用**标题 1**样式，条目用五号、悬挂缩进 2 字符。

示例：

```
[1] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
[2] 作者. 书名[M]. 出版地: 出版社, 年: 页码.
[3] 作者. 题名[D]. 保存地: 保存单位, 年.
```

## 七、声明（必须三段）

1. **数据与代码可用性**：已公开（给链接/DOI）/ 可索取（说明向谁要、多久回应）/ 受限（说明原因）。
2. **作者贡献**：按 CRediT 十四类写，如「张三：概念化、方法学；李四：软件、可视化」。
3. **利益冲突**：有就写清；没有写「作者声明无利益冲突」。

## 八、投稿前自检清单

- [ ] 摘要 200–350 字，四要素齐全
- [ ] 一级节 ≥ 3 个，含「方法（或论证框架）」与「讨论」
- [ ] 所有图表都有编号与标题，且正文显式引用（「见图 2」）
- [ ] 参考文献 ≥ 8 条，全部可核（有 DOI 的必须给 DOI）
- [ ] 三段声明齐全
- [ ] 全篇套用样式，没有空格缩进、没有手动编号
- [ ] 导出 PDF 检查：标题层级、图表位置、公式是否错位

## 九、导出与提交

- 同时提交 **.docx 源文件** 与 **PDF**（PDF 用于同行评审，源文件用于排版）。
- 文件名：`第一作者姓-年份-短标题.docx`，例如 `张-2026-面条抗肿瘤.docx`。
- 图表可另附高清原图（PNG/TIFF，300 dpi），在正文中注明「另附原图 图1.png」。

---

**排版问题怎么办**：编辑部只做规范化（统一字体、标题层级、图表格式、参考文献格式），
**不改内容、不改叙述方式、不改核心论点**。如果你发现自己的稿子被改了措辞，请立即联系编辑部。
