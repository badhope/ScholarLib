# 内容生态设定（v1.11 唯一口径）

> 本站的内容生态按「编辑部的世界观」配套设计：每一条设定都要能互相解释，
> 不允许两套口径并存。本文是唯一事实源，改设定先改这里。

## 一、四条不可违反的设定

1. **内容不分等级。** 内容没有三六九等，只有类别（academic/fun/rant）。
   RQS 是**审稿工具**的产出，不是内容的公开分层；等级徽章不得出现在列表、
   卡片、首页、归档等浏览面，只允许出现在详情页「评审信息」区。
2. **层级只挂创作者。** 等级（L1–L9 经验阶梯）属于账号，由 XP 驱动，
   与内容质量无关。读者看到的作者头衔来自账号等级，不来自文章分数。
3. **同类别才可比对。** 排行、推荐、相似内容只在同一 content_category
   内比较；跨类别比较是设定外的错误用法。
4. **已发布必有封面。** 无封面资源不得以裸态上线；物化与发布链路按学科
   自动回填默认封面（13 门类 × 3 图，确定性轮转）。

## 二、类别判定（编辑部唯一标准）

| 类别 | 判定 | 典型形态 |
| --- | --- | --- |
| academic 学术研究 | 真问题 + 真方法，结论可核 | 实证/综述/方法论文 |
| fun 娱乐向 | 戏仿、玩梗、整活，但方法自洽 | 荒诞指数 2.5–7.5 |
| rant 吐槽向 | 立场先行的吐槽/评论体 | 荒诞指数 ≥7.5 或明确评论体裁 |

判定顺序：编辑部显式指定 > 荒诞指数折算 > 类型兜底（paper→academic）。
同一篇内容只有一个类别，不允许并列。

## 三、风格光谱（不是等级）

荒诞指数 0–10 是**风格坐标**，四档文案为：学术 / 轻娱乐 / 娱乐 / 吐槽。
它描述「这篇内容站在光谱的哪里」，不评价好坏，不参与排序。

## 四、编辑职权链

主编（chief_editor）＝ 副主编（deputy_editor）＞ 编委/栏目编辑
（board_editor/section_editor）＞ 执行编辑（editor）＞ 审稿人（reviewer）

- 终审四元决定（录用/小修/大修/拒稿）：仅主编、副主编（admin 视同）。
- 初筛、送审、推荐：编委、执行编辑。
- 评审意见：审稿人；作者只可见匿名化后的意见。
- 终审集中的理由：口径统一、责任可追溯，避免编委互推翻。

## 五、评审流程（学术界完整标准）

1. 投稿（pending）→ 编辑部初筛（desk screening）
2. 送审：双盲分配 ≥2 名审稿人（可加第三仲裁）
3. 审稿人接受/拒邀 → 提交意见 + RQS 七维评分
4. 意见返回 → 主编/副主编四元决定
5. 小修/大修 → 作者修回（resubmitted）→ 复审
6. 录用 → 排期（draft）→ 刊出（published）
7. 全流程审计留痕（audit_logs）
